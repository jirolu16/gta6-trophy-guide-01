**Leonida Legend** is a complete GTA VI trophy guide and platinum tracker. It covers all 55 official PlayStation trophies (1 platinum, 2 gold, 6 silver, 46 bronze, 28 hidden) with an original, source-cited guide for every trophy, a four-stage roadmap to platinum (about 200 hours, difficulty 4/10), a dedicated missables page, and a spoiler-safe checklist that saves progress in the browser: earned tracking with per-grade counts, counters for target-based trophies, grade and kind filters, search, hide-earned and missable-only toggles, and JSON export/import. The app is fully static and offline; every asset is local.

## Run it

```sh
node main.ts   # builds the dossier and copies the app into ./output
python3 -m http.server 8000 --directory app   # then open http://localhost:8000 for the tracker
```
